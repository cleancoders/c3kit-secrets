# Security Policy

## Supported Versions

The most recent published `0.x` release on Clojars receives security fixes.

| Version | Supported          |
| ------- | ------------------ |
| 0.x     | :white_check_mark: |

## Reporting a Vulnerability

Please report security issues privately via [GitHub's "Report a vulnerability"](https://github.com/cleancoders/c3kit-secrets/security/advisories/new) workflow, or by emailing the maintainer at gina@cleancoders.com. Do not open a public issue for security-sensitive reports.

We aim to acknowledge reports within 5 business days.
