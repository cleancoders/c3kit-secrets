### 0.1.0
 * First release. `c3kit.secrets` loads secrets and configuration through a pluggable `Source`: `:ssm` (AWS SSM Parameter Store at `/{env}/{scope}/{key}`, the primary source; one decrypted, paginated `GetParametersByPath` per scope), `:memory` (development and specs), `:chain` (first value found wins, for migrations), and `:secrets-manager` (AWS Secrets Manager at `{scope}/{env}/{key}`; transitional, deprecated on arrival — exists only to migrate off Secrets Manager). API: `get-value` / `get-value!`, `load-all` / `load-all!` (flat keyword map; the `!` variants throw naming missing keys, never values), `close`, and every source is `Closeable`. JVM only; the AWS SDK's async Netty client is excluded.
